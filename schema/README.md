# Generated schemas

`cdm-config.schema.json` is generated from `cdm_config::CdmConfig` by `cargo xtask docs`
(`CFG-003`, `OPS-012`). It is checked in so that editors and the web UI can consume it without a
build step, and CI fails if it drifts from the Rust types.

It lands in PR #4; see [`docs/ROADMAP.md`](../docs/ROADMAP.md).
