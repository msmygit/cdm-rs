# API documentation

The rustdoc for every crate in the workspace is published alongside this book, under
[`/api`](api/index.html). It is generated by `cargo doc --workspace --no-deps --all-features`
on every push to `main` and is the reference for the public Rust API; this book is the reference
for behaviour and design.

| Crate | Rustdoc | Responsibility |
|---|---|---|
| `cdm-core` | [`cdm_core`](api/cdm_core/index.html) | Domain vocabulary, error model, plugin registry |
| `cdm-config` | [`cdm_config`](api/cdm_config/index.html) | The one typed configuration model (ADR-0005) |
| `cdm-codec` | [`cdm_codec`](api/cdm_codec/index.html) | CQL value conversion and codecs |
| `cdm-cql` | [`cdm_cql`](api/cdm_cql/index.html) | The only crate that talks to the CQL driver (ADR-0002) |
| `cdm-feature` | [`cdm_feature`](api/cdm_feature/index.html) | Feature plugins (constant columns, explode map, …) |
| `cdm-track` | [`cdm_track`](api/cdm_track/index.html) | Run tracking and resumability |
| `cdm-cluster` | [`cdm_cluster`](api/cdm_cluster/index.html) | Lease-based coordination (ADR-0003) |
| `cdm-metrics` | [`cdm_metrics`](api/cdm_metrics/index.html) | Counters, Prometheus, OpenTelemetry |
| `cdm-engine` | [`cdm_engine`](api/cdm_engine/index.html) | The migrate and validate execution engine |
| `cdm-service` | [`cdm_service`](api/cdm_service/index.html) | Run orchestration behind the interfaces |
| `cdm-api` | [`cdm_api`](api/cdm_api/index.html) | The OpenAPI control plane (ADR-0004) |
| `cdm-mcp` | [`cdm_mcp`](api/cdm_mcp/index.html) | MCP interface, generated from the API |
| `cdm-a2a` | [`cdm_a2a`](api/cdm_a2a/index.html) | A2A interface, generated from the API |
| `cdm-ui` | [`cdm_ui`](api/cdm_ui/index.html) | Terminal UI |
| `cdm-cli` | [`cdm_cli`](api/cdm_cli/index.html) | The `cdm` binary |
| `cdm-testkit` | [`cdm_testkit`](api/cdm_testkit/index.html) | Shared test fixtures and harnesses |

The crate topology, and the dependency edges that are allowed between these crates, are defined
in [Architecture §3](docs/ARCHITECTURE.md).
